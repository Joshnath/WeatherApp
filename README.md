## Overview 
WeatherApp is a JavaFX app that shows the user the current day summary and a 3 day projected forecast summary for Chicago, Illinois. The app uses weather API data to show the current temperature, detailed forecast conditions, hourly temperatures, and a 3-day forecast with day/night temperatures, weather icons, wind speed, and wind direction.

## Technologies Used
- Java 11
- JavaFX
- Maven
- JUnit
- Git
- GitHub

## Skills Used
- JavaFX GUI development
- API integration
- Data parsing and formatting

## How to run
1. Clone the repository
2. Open the folder with the desired IDE and run JavaFX.java
